# VibeCode Product Specification v5.1.0

## Overview

VibeCode is an AI-powered development environment combining a native desktop app with a lightweight Linux VM running essential development services.

**Version:** v5.1.0-beta
**Platforms:** macOS (Apple Silicon), Linux, Windows
**Architecture:** Tauri Desktop + Alpine Linux VM + 5-Service Stack

---

## 1. Core Components

### 1.1 Desktop Application

| Component | Technology | Version |
|-----------|------------|---------|
| Framework | Tauri | 2.9.1 |
| Backend | Rust | Latest |
| Native UI | Swift 5 | macOS |
| Editor | Monaco | 0.55.1 |

**Features:**
- Native macOS menubar with status indicators
- Real-time service monitoring
- One-click VM control (Start/Stop)
- Console viewer for VM output
- Automatic port forwarding to localhost

### 1.2 Virtual Machine Infrastructure

| Component | Technology | Details |
|-----------|------------|---------|

### 1.3 Services Stack (5-Service Architecture)

| Service | Port (VM) | Port (localhost) | Description |
|---------|-----------|------------------|-------------|
