# VibeCode Sample Project

Welcome to your first VibeCode project! This sample demonstrates key features of VibeCode's AI-powered development environment.

## What's Included

- **TypeScript Setup**: Modern TypeScript configuration with strict type checking
- **API Endpoint**: A simple "Hello World" API to demonstrate code completion
- **AI-Ready Comments**: Examples of how to write comments that work well with AI assistance
- **Sample Tasks**: Pre-configured tasks in `.vibecode/tasks.json` for quick experimentation

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Build the Project**
   ```bash
   npm run build
   ```

3. **Run the Application**
   ```bash
   npm start
   ```

4. **Try AI Features**
   - Open `src/api/hello.ts` in VibeCode
   - Start typing and watch AI code completion suggestions
   - Try asking the AI to add new features
