# VibeCode v1.1.0

## 🚀 What's New
- **vfkit VM Integration**: Now boots a Linux VM with vfkit before starting code-server
- **Datadog Tracing**: Full tracing of VM boot process (20-second boot time tracked)
- **Professional VS Code development environment**
- **Cross-platform desktop application**  
- **Automatic code-server integration**
- **Clean Dark+ theme with no welcome screens**

## 📦 Downloads

### macOS
- **DMG Installer**: `VibeCode-v1.1.0.dmg` - Drag and drop installation
- **App Bundle**: `VibeCode-v1.1.0.app` - Direct application bundle

## 🛠️ Installation

### macOS DMG Installation
1. Download `VibeCode-v1.1.0.dmg`
2. Double-click to mount the disk image
3. Drag VibeCode to your Applications folder
4. Launch from Applications or Spotlight search

### macOS App Bundle Installation
1. Download `VibeCode-v1.1.0.app`
2. Move to Applications folder
3. Launch directly

- **VM Technology**: vfkit (Apple Virtualization framework)
- **Boot Time**: ~20 seconds (tracked with Datadog)
- **VM Resources**: 2 CPUs, 2GB RAM
- **Tracing**: Full Datadog APM integration for VM lifecycle
