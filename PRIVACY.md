# VibeCode Privacy Policy

**Last Updated:** December 2024

## Overview

VibeCode is a local virtualization application that runs entirely on your Mac.
We are committed to protecting your privacy.

## Data Collection

**VibeCode does NOT collect, transmit, or store any personal data.**

Specifically:
- ❌ No telemetry or analytics
- ❌ No crash reporting to external servers
- ❌ No usage tracking
- ❌ No personal information collection
- ❌ No network connections to our servers

## Local Data Storage

VibeCode stores the following data **locally on your Mac only**:

1. **Virtual Machine Files** (`~/Library/Application Support/VibeCode/`)
   - VM disk images
   - VM configuration files
   - Console logs (local only)

2. **Application Preferences** (macOS defaults system)
   - Window size and position
   - Resource allocation settings

## Network Usage

VibeCode uses the network for:

1. **Virtual Machine NAT Networking**
   - VMs access the internet through macOS NAT
   - This is standard VM networking, not data collection

2. **Optional: Disk Image Downloads**
   - On first launch, you may choose to download pre-built VM images
   - Downloads are from GitHub releases (github.com)
   - No authentication or tracking required

## Third-Party Services

If you choose to install optional software inside your VMs (e.g., Datadog),
those services have their own privacy policies. VibeCode does not pre-install
any telemetry or analytics software.

## Open Source

VibeCode is open source. You can audit the complete source code at:
https://github.com/ryanmaclean/vibecode-webgui

We will update this privacy policy as needed. Check our GitHub repository
