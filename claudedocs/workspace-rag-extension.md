# Workspace RAG Extension

Production-ready VS Code extension with AI-powered workspace-aware code assistance using RAG.

## Key Features

- Multi-LLM Support (OpenAI, Anthropic, Google, OpenRouter) with BYOK
- Local MLX acceleration for Apple Silicon  
- pgvector integration with PostgreSQL
- Enterprise security safeguards
- Full Datadog tracing and observability
- Comprehensive testing and CI/CD
