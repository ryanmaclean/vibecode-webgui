# Changelog

All notable releases of VibeCode are documented here.

## [v5.1.0-beta](https://github.com/ryanmaclean/vibecode-webgui/releases/tag/v5.1.0-beta) - 2026-01-31

Latest pre-release. Frontend integration, Docker validation, Zod v4 compatibility,
auto-update system, cost tracking, model comparison, Linux builds, VM snapshots,
and multi-VM support.

## [v4.2.0](https://github.com/ryanmaclean/vibecode-webgui/releases/tag/v4.2.0) - 2026-01-16

Enhanced menubar app. Production-ready macOS menubar application with complete
development environment.

## [v4.1.0](https://github.com/ryanmaclean/vibecode-webgui/releases/tag/v4.1.0) - 2026-01-15

Native macOS menubar app. Launch Alpine Linux VM with OpenVSCode Server with one
click. 100% Apple Virtualization with no external VM tooling required.

## [v4.0.1](https://github.com/ryanmaclean/vibecode-webgui/releases/tag/v4.0.1) - 2026-01-17

Patch release for v4.0.0.

## [v4.0.0](https://github.com/ryanmaclean/vibecode-webgui/releases/tag/v4.0.0) - 2026-01-15

Production release with menubar app, green console theme, and Datadog integration.

## [v3.3.0](https://github.com/ryanmaclean/vibecode-webgui/releases/tag/v3.3.0) - 2026-01-14
