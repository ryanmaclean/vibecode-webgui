INIT SCRIPT FIXES
================================================================================

Original problematic line (656):
IP=$(ip -4 addr show eth0 | grep -oP '(?<=inet\s)\d+(\.\d+){3}' | head -1)

After automatic sed fix:
IP=$(ip -4 addr show eth0 | grep -o '[0-9]\+\.[0-9]\+\.[0-9]\+\.[0-9]\+' | head -1)

Changes:
- grep -P → grep -E (BusyBox compatible)
- (?<=inet\s)\d+(\.\d+){3} → [0-9]\+\.[0-9]\+\.[0-9]\+\.[0-9]\+
- Lookbehind removed (not supported by grep -E)
- Simple pattern that works with BusyBox

QUICK REFERENCE: What Each Fix Does
================================================================================

Fix 1: shadow package
→ Provides /usr/bin/su
→ Allows: su postgres -c '/usr/bin/postgres'
→ Without it: "su: command not found"

Fix 2: coreutils package
→ Provides /usr/bin/cut
→ Allows: cut -d= -f2 (parse DD_API_KEY=value)
→ Without it: "cut: command not found"

Fix 3: util-linux package
→ Provides additional mount utilities
→ Better compatibility with systemd-style mounts
→ Improves overall system stability

Fix 4: grep compatibility
→ Converts grep -P to grep -E
→ Converts lookbehind regex to simple pattern
→ Without it: "grep: unrecognized option: P"

Fix 5: kernel awareness
→ Documents virtio_net requirement
→ Warns about networking dependencies
→ Without it: eth0 not found, no IP address

Fix 6: validation
→ Catches missing commands before packaging
→ Reports issues early with clear messages
→ Without it: fail at runtime with cryptic errors
