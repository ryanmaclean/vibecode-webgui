Boot Sequence
=============

1. VM Start
   └─► Load Kernel (vmlinuz)
       └─► Load Initramfs (bun-openvscode-with-ssh.cpio.gz)
           └─► Execute /init script
               │
               ├─► Mount Filesystems (/proc, /sys, /dev, /tmp)
               │
               ├─► Load Network Drivers (virtio_net)
               │
               ├─► Configure Network (DHCP via udhcpc)
               │   └─► Obtain IP: 192.168.64.3
               │
               ├─► Start SSH Server
               │   ├─► Create directories (/etc/dropbear, /root/.ssh)
               │   ├─► Set root password (password)
               │   ├─► Generate host keys (RSA, ECDSA)
               │   └─► Start dropbear (port 22)
               │
               └─► Start OpenVSCode
                   ├─► Set environment (PORT=3000, HOST=0.0.0.0)
                   ├─► Change to /opt/openvscode
                   └─► Execute bun run bun-server.js

2. Host Connects
   └─► Run tunnel-to-vm.sh
       ├─► Test VM reachability (ping)
       ├─► Test SSH port (nc -z)
       ├─► Check local port availability
       └─► Establish SSH tunnel
           └─► ssh -L 3000:127.0.0.1:3000 root@192.168.64.3

3. Browser Access
   └─► Open http://localhost:3000
       └─► Request forwarded through SSH tunnel
           └─► Reaches OpenVSCode at VM's 127.0.0.1:3000

Security
========

Current (Development):
- Authentication: Password (root:password)
- Encryption: SSH (RSA/ECDSA)
- Access: Root user
- Network: Host-only (192.168.64.0/24)

Recommended (Production):
- Authentication: SSH keys only
- Encryption: SSH with strong ciphers
- Access: Non-root user with sudo
- Network: Firewall with whitelist
- Monitoring: SSH audit logs

Troubleshooting Checklist
==========================

□ VM boots successfully
  └─► Check: ./scripts/view-vm-logs.sh

□ Network configured
  └─► Look for: "DHCP successful: 192.168.64.3/24"

□ SSH server started
  └─► Look for: "Dropbear SSH server started successfully"

□ OpenVSCode started
  └─► Look for: "Starting OpenVSCode Server"

□ VM reachable
  └─► Test: ping -c 1 192.168.64.3

□ SSH port open
  └─► Test: nc -z 192.168.64.3 22

□ SSH connection works
  └─► Test: ssh root@192.168.64.3 (password: password)

□ Tunnel established
  └─► Test: ./scripts/tunnel-to-vm.sh 192.168.64.3

□ OpenVSCode accessible
  └─► Test: curl http://localhost:3000

□ Web interface loads
  └─► Open: http://localhost:3000 in browser
