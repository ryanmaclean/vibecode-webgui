                    VSOCK PROXY SERVER FIX - SUMMARY

ROOT CAUSE IDENTIFIED
---------------------

The vsock proxy server wasn't starting because of DUPLICATE socket device
configuration. Two parts of the code were both configuring socket devices,
causing one to overwrite the other.

Location 1: BaseVMManager.configureStandardDevices() (line 654)
    → config.socketDevices = [socketDevice]  ← OVERWRITES!

Location 2: NATNetworkStrategy.configure() (line 185)
    → config.socketDevices = [socketDevice]  ← GOT OVERWRITTEN!

EXECUTION ORDER (The Problem):
    1. NATNetworkStrategy.configure()     adds socket device
    2. BaseVMManager.configureStandardDevices()  REPLACES it
    3. VM starts with wrong socket device
    4. startProxyServer() finds empty socketDevices array
    5. Proxy fails to start (no device available)


THE FIX
-------

✓ CHANGE 1: Remove duplicate from BaseVMManager
    File: Shared/Core/BaseVMManager.swift
    - Removed socket device configuration
    - Removed network device configuration
    - Now only configures: entropy, platform
    - Networking is now ONLY handled by NetworkingStrategy

✓ CHANGE 2: Add initialization delay
    File: Shared/Networking/NATNetworkStrategy.swift
    - Added 500ms delay before accessing vm.socketDevices
    - Allows VM to fully initialize internal device arrays
    - Uses weak references to prevent retain cycles
