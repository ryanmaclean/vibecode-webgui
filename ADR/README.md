# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) that document key architectural decisions made for the VibeCode project.

## ADR Format

Each ADR follows this structure:
- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: The situation that led to the decision
- **Decision**: The decision that was made
- **Consequences**: The impact of the decision

## Creating New ADRs

1. Create a new file: `ADR-XXX-title.md`
2. Use the template from existing ADRs
3. Get team review and approval
4. Update this index

For more information about ADRs, see [Architecture Decision Records](https://adr.github.io/).
