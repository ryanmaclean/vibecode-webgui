## Safe Merge Options

### Option A: Three-Way Merge with Conflict Resolution Strategy
Keep all local source code, accept remote for infrastructure:

```bash
# Use merge strategy to favor local for src/, remote for everything else
git merge origin/main \
  -X ours \
  --no-commit

# Then selectively accept remote for specific paths
git checkout --theirs .github/workflows/
git checkout --theirs src-tauri/
git checkout --theirs infrastructure/

# Review and commit
git status
git commit -m "merge: integrate Tauri work while preserving local changes"
```

### Option B: Merge with Automatic Conflict Resolution
```bash
# Accept theirs for node_modules, build artifacts
git merge origin/main -X theirs --no-commit

# Then restore our source code
git checkout HEAD -- src/
git checkout HEAD -- tests/

# Manually review conflicts in config files
git status
```

### Option C: Create Patch and Reapply (Safest)
```bash
# 1. Create patch of all local source changes
git diff origin/main..main -- src/ tests/ > local-source-changes.patch

# 2. Reset to remote
git reset --hard origin/main

# 3. Apply patch
git apply local-source-changes.patch

# 4. Resolve any conflicts manually
```

## Recommended: Option C (Patch Method)

This is safest because:
1. ✅ Explicitly preserves all source code
2. ✅ Gets clean Tauri infrastructure from remote
3. ✅ Only conflicts are real code differences
4. ✅ Easy to review what's being merged
