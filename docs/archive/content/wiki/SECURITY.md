## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing [security@vibecode.dev](mailto:security@vibecode.dev) or by opening a private GitHub security advisory.
Please include as much detail as possible to help us resolve the issue quickly:

1. A description of the issue, affected hosts/routes, and observed impact.
2. Proof-of-concept steps or minimal reproduction (scripts, HAR files, etc.).
3. Any known exploitation or mitigation context.

For urgent incidents (active exploitation or data exposure), notify the on-call platform engineer through the incident channel immediately after sending the email so we can coordinate within minutes.

 * Acknowledgement: We will acknowledge receipt of your report within 2 business days.
 * Updates: You can expect updates on the status of your report at least once per week.
 * Resolution: Once the vulnerability is validated, we will provide an estimated timeline for a fix. If the report is declined, we will provide a clear explanation.
