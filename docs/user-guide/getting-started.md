## Creating Your First Workspace

A workspace is like a project folder where you keep all your code and files together.

### Steps to Create a Workspace

1. **Click the "New Workspace" button**
   - Located at the top of the Workspaces page

2. **Choose a name**
   - Use something descriptive like "My First Project" or "Python Practice"
   - Avoid special characters (stick to letters, numbers, spaces)

3. **Select a template** (optional)
   - Python: For Python programming
   - Node.js: For JavaScript projects
   - Empty: Start from scratch
   - *For your first workspace, try "Python" or "Empty"*

4. **Click "Create"**
   - Your workspace will be ready in a few seconds

[Screenshot: Create workspace dialog with name field and template options]

💡 **Tip**: You can create as many workspaces as you need. Each one is separate and independent.

## Your First Code

Let's write a simple program to see how everything works.

### Writing "Hello, World!"

1. **Open your workspace**
   - Click on the workspace you just created

2. **Create a new file**
   - Click the file icon or right-click in the file explorer
   - Name it `hello.py` (for Python) or `hello.js` (for JavaScript)

3. **Write your code**

   For Python:
   ```python
   print("Hello, World!")
   ```

   For JavaScript:
   ```javascript
   console.log("Hello, World!");
   ```

4. **Save the file**
   - Press `Ctrl+S` (Windows/Linux) or `Cmd+S` (Mac)
   - Or click File → Save

[Screenshot: Code editor with hello world program]

### Running Your Code

1. **Open the terminal**
   - Look for the terminal panel at the bottom
   - Click "Terminal" if it's not visible

2. **Type the command**

   For Python:
   ```bash
   python hello.py
   ```

   For JavaScript:
   ```bash
   node hello.js
   ```

3. **Press Enter**
   - You should see "Hello, World!" printed in the terminal

[Screenshot: Terminal showing command and output]

🎉 **Congratulations!** You've just written and run your first program in VibeCode!

## Getting Help from the AI Assistant

The AI assistant can help you learn and solve problems.

### How to Ask for Help

1. **Click the AI Assistant icon**
   - Usually on the right side of the screen
   - Look for a chat or robot icon

2. **Type your question**
   - Examples:
     - "How do I create a list in Python?"
     - "What does this error mean?"
     - "Help me write a function to add two numbers"

3. **Review the response**
   - The AI will explain concepts and show code examples
   - You can ask follow-up questions

[Screenshot: AI assistant conversation example]

💡 **Tip**: Be specific with your questions. Instead of "Help me", try "How do I read a file in Python?"

## Common First-Time Questions

### How do I save my work?
Your work is automatically saved in the cloud. You can also manually save with `Ctrl+S` or `Cmd+S`.

### Can I access my workspace from another computer?
Yes! Your workspaces are stored online. Just log in from any computer.

### What happens if I close the browser?
Nothing bad! Your workspace is saved. When you come back, everything will be right where you left it.

### Can I undo mistakes?
Yes! Use `Ctrl+Z` (Windows/Linux) or `Cmd+Z` (Mac) to undo changes in the code editor.

### Is my code private?
Yes, your workspaces are private to you unless you choose to share them.
