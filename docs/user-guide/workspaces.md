# Managing Workspaces

Learn how to create, organize, and manage your coding projects in VibeCode.

## What is a Workspace?

A workspace is your personal coding environment for a project. Think of it as a folder on your computer that contains:

- All your code files
- A code editor to write and edit
- A terminal to run commands
- An AI assistant to help you

Each workspace is independent, so you can have different projects without them interfering with each other.

## Creating a Workspace

### Basic Steps

1. **Go to the Workspaces page**
   - Click "Workspaces" in the navigation bar
   - Or click the VibeCode logo

2. **Click "New Workspace"**
   - Big button at the top of the page

3. **Fill in the details**
   - **Name**: Give it a clear, descriptive name
   - **Template**: Choose what type of project (optional)
   - **Description**: Add notes about the project (optional)

4. **Click "Create"**
   - Wait a few seconds for setup

[Screenshot: New workspace creation dialog]

### Choosing a Template

Templates give you a head start with pre-configured settings:

**Empty**
- Start with a blank slate
- Good for: Any project, learning, experimenting

**Python**
- Pre-configured for Python development
- Good for: Python scripts, data analysis, learning Python

**Node.js**
- Set up for JavaScript/Node.js
- Good for: Web apps, APIs, JavaScript projects

**React**
- Ready for React web development
- Good for: Building user interfaces, web apps

💡 **Tip**: Not sure which template? Start with "Empty" - you can install anything you need later.

## Organizing Your Workspaces

### Naming Best Practices

**Good Names:**
- "Python Calculator"
- "Website Portfolio"
- "Data Analysis Project"

**Avoid:**
- "Project1", "Test", "New" (too vague)
- Special characters like `!@#$%`

### Using Folders in Workspaces

Keep your workspace organized with folders:

1. **Right-click in the file explorer**
2. **Select "New Folder"**
3. **Name it something meaningful**
   - Examples: `src`, `images`, `tests`, `docs`

[Screenshot: Right-click context menu with "New Folder" option]

### Project Structure Example

```
My Website Project/
├── index.html
├── styles/
│   └── main.css
├── scripts/
│   └── app.js
└── images/
    └── logo.png
```

## Managing Workspaces

### Renaming a Workspace

1. Go to the Workspaces page
2. Find your workspace
3. Click the settings icon (⚙️) or three dots (⋯)
4. Select "Rename"
5. Enter the new name
6. Click "Save"

[Screenshot: Workspace card with settings menu open]

### Deleting a Workspace

⚠️ **Warning**: Deleting is permanent! Make sure you've backed up anything important.

1. Go to the Workspaces page
2. Find the workspace to delete
3. Click the settings icon (⚙️) or three dots (⋯)
4. Select "Delete"
5. Confirm the deletion

💡 **Tip**: If you're not sure, rename it to "OLD - Project Name" instead of deleting. You can delete it later if you're certain.

### Duplicating a Workspace

Create a copy of a workspace to experiment without changing the original:

1. Go to the Workspaces page
2. Find the workspace to copy
3. Click the settings icon
4. Select "Duplicate"
5. Give the new workspace a name
6. Click "Create"

## Sharing Workspaces

### When to Share

- Working on a group project
- Getting help from a teacher or mentor
- Showing your work to others

### How to Share

1. **Open the workspace**
2. **Click the Share button**
   - Usually in the top right corner
3. **Choose sharing options**
   - View only: Others can see but not edit
   - Edit access: Others can make changes
4. **Copy the share link**
5. **Send the link to others**

[Screenshot: Share dialog with permission options]

⚠️ **Privacy Note**: Only people with the link can access your shared workspace.

## Workspace Settings

### Accessing Settings

1. Open your workspace
2. Click Settings (⚙️ icon)
3. Adjust options as needed

### Common Settings

**Auto-Save**
- Automatically saves your work
- Recommended: Keep this ON

**Tab Size**
- How many spaces for indentation
- Common values: 2 or 4 spaces

**Theme**
- Light or dark color scheme
- Choose what's comfortable for your eyes

**Font Size**
- Make text larger or smaller
- Adjust for readability

## Working Across Multiple Workspaces

### Switching Workspaces

**Quick Method:**
1. Click the workspace name in the top bar
2. Select another workspace from the dropdown

**Full Method:**
1. Click "Workspaces" in the navigation
2. Choose a different workspace

### Moving Files Between Workspaces

Currently, files need to be copied manually:

1. Open the file in the first workspace
2. Copy the contents (`Ctrl+A`, then `Ctrl+C`)
3. Switch to the other workspace
4. Create a new file
5. Paste the contents (`Ctrl+V`)

💡 **Tip**: For many files, consider downloading the workspace and uploading to the other workspace.

## Workspace Limits

Depending on your account, you may have limits:

- **Number of workspaces**: Check your account settings
- **Storage per workspace**: Usually generous for code projects
- **Concurrent workspaces**: How many you can have open at once

If you need more, consider cleaning up old workspaces or upgrading your account.

## FAQ

### How many workspaces can I create?
Check your account settings for limits. Most users can create many workspaces.

### Are my workspaces backed up?
Yes, workspaces are stored in the cloud. However, it's good practice to download important projects regularly.

### Can I work offline?
No, VibeCode requires an internet connection. Make sure you have stable internet access.

### What happens to idle workspaces?
Workspaces may shut down after inactivity to save resources. Your files are safe - just reopen the workspace to continue.

### Can I import existing projects?
Yes! Use the file upload feature to import your existing code. See the [File Management Guide](file-management.md) for details.

### How do I export a workspace?
Download your files individually or use the terminal to create a zip file of your project.

### Can I restore a deleted workspace?
Deletion is usually permanent. Contact support immediately if you accidentally deleted important work.

### Why can't I open my workspace?
Common issues:
- Internet connection problems
- Browser cache issues (try refreshing)
- Workspace may be starting up (wait 30 seconds)
- See [Troubleshooting](troubleshooting.md) for more help

## Best Practices

✅ **Do:**
- Use clear, descriptive names
- Organize files in folders
- Delete workspaces you no longer need
- Back up important projects regularly
- Use templates to save setup time

❌ **Don't:**
- Create dozens of "test" workspaces
- Store sensitive information (passwords, API keys)
- Share workspaces publicly without reviewing content
- Leave many workspaces running simultaneously
