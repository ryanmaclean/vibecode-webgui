## Phase 1: removed in this PR

477 files were untracked, bringing the tree from 220.9 MB to 119.9 MB (−46%). Each file is reproducible build output, a cache, runtime state, or a backup copy. Nothing outside the removed set references them. The one exception is `docs/src/env.d.ts`, whose triple-slash reference to `../.astro/types.d.ts` is regenerated by `astro sync`, `astro dev` and `astro build`, which is standard for Astro.

| Removed | Files | Why it is safe |
|---|---:|---|
| `td/tools/kafka_tui/target/` | 400 | Cargo build output; `Cargo.toml` and `src/` stay |
| `docs/.astro/` | 8 | Astro cache, already in `.gitignore`; regenerated by `astro sync` |
| `**/__pycache__/*.pyc` | 19 | already in `.gitignore` |
| `test-results/` outputs (azure SwiftUI, tests/e2e, docs) | 22 | already in `.gitignore`; test run output |
| `gitea/data/`, `gitea/log/` | 14 | local Gitea runtime DB, indexes, queues and logs (see the security note) |
| `mbp_m1/.beads-backups/` | 1 | old beads DB backup |
| `*.backup`, `*.bak`, `*.bak.<timestamp>` | 13 | copies of files that still exist under their real names (a 14th, `CURRENT.bak`, is counted under `gitea/data/`) |

`.gitignore` now covers every pattern above, so these files cannot come back. The pre-removal copies of `gitea/data`, `gitea/log` and `mbp_m1/.beads-backups` from the owner's working checkout were preserved outside the repo before this change.

Note: when a checkout pulls this change, git deletes these files from its working tree. No running service was using them. At the time of the change, no Gitea process was serving `gitea/data`, which was last modified 2026-02-15.

## Security note (owner action)

The repository is **public**. The following are still tracked, and they are also in history:

- `gitea/custom/app.ini` contains `INTERNAL_TOKEN` and `JWT_SECRET` values.
- `gitea/data/gitea.db` held the Gitea users table. It is removed from the tree by this PR, but it remains in history.

If the Gitea instance behind `ROOT_URL = http://studio.local:3000/` is still used, or these values are reused anywhere, rotate them. Removing them from history needs a history rewrite, which #2125 defers ("No history rewrite yet"). That is an owner decision. The values are not reproduced in this report.
