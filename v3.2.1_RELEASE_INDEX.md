## Installation Quick Start

### 5-Minute Installation

```bash
# 1. Download DMG
cd ~/Downloads
# Download VibeCode-Unified-v3.2.1-Datadog.dmg (253 MB)

# 2. Verify checksum (optional)
shasum -a 256 VibeCode-Unified-v3.2.1-Datadog.dmg
# Should match: 837a77f0c5f39873245d89d3449986590a8586759ecfcf1dae8499711aaa9aff

# 3. Mount DMG
hdiutil mount VibeCode-Unified-v3.2.1-Datadog.dmg

# 4. Copy app
cp -r "/Volumes/VibeCode Unified/UnifiedServicesVibeCodeApp.app" /Applications/

# 5. Eject and launch
hdiutil eject "/Volumes/VibeCode Unified"
open /Applications/UnifiedServicesVibeCodeApp.app

# 6. Wait 2 minutes for boot
echo "⏳ Waiting for VM to boot..."
sleep 120

# 7. Verify services
curl -I http://localhost:8080 && echo "✅ All ready"
```

### System Requirements

- **OS**: macOS 13.0+ (Ventura)
- **CPU**: Apple Silicon (M1/M2/M3/M4)
- **RAM**: 4 GB minimum, 8 GB recommended
- **Disk**: 2 GB free

## Upgrade from v3.2.0

### One-Line Upgrade

```bash
cd ~/Downloads && hdiutil mount VibeCode-Unified-v3.2.1-Datadog.dmg && pkill -f UnifiedServicesVibeCodeApp && sleep 2 && rm -rf /Applications/UnifiedServicesVibeCodeApp.app && cp -r "/Volumes/VibeCode Unified/UnifiedServicesVibeCodeApp.app" /Applications/ && hdiutil eject "/Volumes/VibeCode Unified" && open /Applications/UnifiedServicesVibeCodeApp.app && echo "✅ Upgrade complete"
```

## Datadog Extension Usage

### Static Code Analysis (No Setup)

1. Open http://localhost:8080 in browser
2. Click Extensions icon (left sidebar)
3. Datadog extension auto-loaded
4. Open any code file for instant analysis

**Works offline** - No internet or authentication required

### Cloud Integration (Optional)

1. Create Datadog account (if needed)
2. Generate API key in Datadog Dashboard
3. Configure in extension sidebar
4. Authenticate with your account
5. Enable cloud features (dashboards, log streaming, etc.)

**Requires**: Valid Datadog account and internet connection
